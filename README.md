## 🛠️ Como Rodar o Projeto Localmente (Opcional)

Se você deseja rodar este projeto localmente, siga os passos abaixo:

1. **Clone o repositório:**

    ```bash
    git clone [https://github.com/drehseter/portifolio.git](https://github.com/drehseter/portifolio.git)
    ```

2. **Navegue até o diretório do projeto:**

    ```bash
    cd portifolio
    ```

3. **Instale as dependências (se houver):**

    ```bash
    # Exemplo se você usar npm e tiver um package.json
    # npm install
    ```

4. **Abra o arquivo `index.html` no seu navegador.**
    *(Ou, se você tiver um servidor de desenvolvimento, execute o comando apropriado, ex: `npm start`)*
